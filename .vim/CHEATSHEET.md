# vim cheatsheet

Generated by `.vim/cheatsheet.sh` from .vimrc. Custom
mappings below are read out of the config, not hand-copied — re-run the script after
changing a mapping. Defaults tables are vim's own, unaffected by this repo's config.

Notation: `<C-x>` = Ctrl-x, `<M-x>` = Alt-x (Option on macOS), `<S-x>` = Shift-x.
`N`/`I`/`V` = Normal / Insert / Visual mode. See `scripts/keyboard/CHEATSHEET.md` for why
Alt is the in-terminal modifier and how it reaches vim at all.

## Custom overrides (from .vimrc)

| Key | Mode | Action |
| --- | ---- | ------ |
| `<C-Up>` | N/I/V | `<C-u>` |
| `<C-Down>` | N/I/V | `<C-d>` |
| `<C-a>` | N/I/V | `<Home>` |
| `<C-e>` | N/I/V | `<End>` |

### Generated at runtime (loop-built, not a literal `nnoremap` line)

.vimrc builds these from a table rather than writing one `nnoremap` per key, so they don't
show up in the grep above. Two tables: pane/split **focus** and **resize**, both shared
with tmux — at the edge of vim's splits the key hands off to `tmux select-pane` /
`tmux resize-pane` instead of doing nothing. See `s:VimIdeFocus`/`s:VimIdeResize` in
.vimrc and `scripts/keyboard/CHEATSHEET.md` for the full tmux+vim picture.

| Key | Mode | Action |
| --- | ---- | ------ |
| `<M-h>` / `<M-Left>`  | N/I/V | focus split left (else tmux pane left) |
| `<M-j>` / `<M-Down>`  | N/I/V | focus split down (else tmux pane down) |
| `<M-k>` / `<M-Up>`    | N/I/V | focus split up (else tmux pane up) |
| `<M-l>` / `<M-Right>` | N/I/V | focus split right (else tmux pane right) |
| `<M-H>` / `<M-S-Left>`  | N/I/V | narrow split (else tmux pane) |
| `<M-J>` / `<M-S-Down>`  | N/I/V | lengthen split (else tmux pane) |
| `<M-K>` / `<M-S-Up>`    | N/I/V | shorten split (else tmux pane) |
| `<M-L>` / `<M-S-Right>` | N/I/V | widen split (else tmux pane) |

### Other custom behavior (not a keymap)

| Trigger | Mode | Action |
| ------- | ---- | ------ |
| `y` (any yank) | N/V | also copies to the system clipboard, if a clipboard tool is found (pbcopy/wl-copy/xclip/xsel); local only, silent no-op over ssh |
| mouse drag | N | visual selection (`mouse=a`); `ttymouse=sgr` for wide terminals and drag-vs-move |
| PageUp/PageDown | N/I/V | vim's own paging — deliberately **not** remapped |

## Buffers

vim defaults; no custom buffer mappings exist yet.

| Command | Does |
| ------- | ---- |
| `:e {file}` | edit/open a file in the current window |
| `:bn` / `:bp` | next / previous buffer |
| `:b {N\|name}` | jump to buffer by number or name |
| `:ls` / `:buffers` | list open buffers |
| `:bd` | delete (close) current buffer |
| `:bd {N}` | delete buffer N |
| `Ctrl-^` | toggle to the alternate (previously edited) buffer |
| `:w` | write current buffer |
| `:wa` | write all changed buffers |
| `:q` / `:q!` | close window / discard changes and close |
| `:x` / `ZZ` | write if changed, then close |
| `:qa` / `:qa!` | close all windows / discard all and quit |

## Windows and splits

vim defaults, all under the `Ctrl-w` prefix. `<M-h/j/k/l>` and `<M-H/J/K/L>` above are the
custom fast path for focus/resize; everything else here is unmapped default vim.

| Command | Does |
| ------- | ---- |
| `:sp` / `Ctrl-w s` | horizontal split |
| `:vs` / `Ctrl-w v` | vertical split |
| `Ctrl-w w` | cycle to next window |
| `Ctrl-w h/j/k/l` | move focus left/down/up/right |
| `Ctrl-w H/J/K/L` | move the window itself to the far left/bottom/top/right |
| `Ctrl-w =` | equalize all window sizes |
| `Ctrl-w +/-` | grow/shrink height |
| `Ctrl-w </>` | shrink/grow width |
| `Ctrl-w \_` / `Ctrl-w \|` | maximize height / width |
| `Ctrl-w o` | close all windows but this one |
| `Ctrl-w q` / `:close` | close this window |
| `Ctrl-w T` | move window into its own tab |
| `:tabnew`, `gt`, `gT` | new tab, next tab, previous tab |

## Panes (tmux, hosting vim)

Not vim itself, but the layer vim splits live inside. Full table in
`scripts/keyboard/CHEATSHEET.md`; the ones that matter alongside vim:

| Key | Does |
| --- | ---- |
| `Alt-\` | split tmux pane vertical |
| `Alt--` | split tmux pane horizontal |
| `Alt-z` | zoom/unzoom current pane |
| `Alt-w` | kill current pane |
| `Alt-Tab` / `Alt-Shift-Tab` | cycle panes, next/previous — **never** forwarded into vim, the guaranteed way out if focus ever gets stuck |
| `Alt-h/j/k/l`, `Alt-H/J/K/L` | forwarded into vim when the pane runs vim (see above); otherwise move/resize the tmux pane directly |

## Cursor movement — Normal mode

| Key | Does |
| --- | ---- |
| `h j k l` | left / down / up / right |
| `w` / `b` / `e` | next word start / previous word start / word end |
| `0` / `^` / `$` | start of line / first non-blank / end of line |
| `gg` / `G` | first line / last line |
| `{N}G` or `:{N}` | go to line N |
| `{` / `}` | previous / next paragraph |
| `%` | jump to matching bracket |
| `Ctrl-u` **(remapped here)** | vim default: half-page up. In this config, `Ctrl-Up` does this instead |
| `Ctrl-d` **(remapped here)** | vim default: half-page down. In this config, `Ctrl-Down` does this instead |
| `Ctrl-f` / `Ctrl-b` | full page down / up |
| `H` / `M` / `L` | top / middle / bottom of window |
| `*` / `#` | next / previous occurrence of word under cursor |
| `f{c}` / `F{c}` | jump to next/previous occurrence of char `c` on the line |
| `t{c}` / `T{c}` | jump to just before next/previous occurrence of char `c` |
| `m{a}` | set mark `a` |
| two backticks + `{a}`, or `'{a}` | jump to mark `a` (exact position / start of line) |

## Editing — Normal mode

| Key | Does |
| --- | ---- |
| `i` / `a` | insert before / after cursor |
| `I` / `A` | insert at start / end of line |
| `o` / `O` | open new line below / above, enter insert mode |
| `x` / `X` | delete char forward / backward |
| `dd` | delete (cut) line |
| `dw`, `de`, `d$`, `d0` | delete to next word / word end / end of line / start of line |
| `cc` / `cw` | change line / change word (delete + insert) |
| `yy` | yank (copy) line — **also copies to system clipboard here** |
| `p` / `P` | paste after / before cursor |
| `u` / `Ctrl-r` | undo / redo |
| `.` | repeat last change |
| `r{c}` | replace char under cursor with `c` |
| `~` | toggle case of char under cursor |
| `>>` / `<<` | indent / outdent line |
| `{N}{cmd}` | prefix any of the above with a count, e.g. `3dd` deletes 3 lines |
| `v` / `V` / `Ctrl-v` | start visual / visual-line / visual-block selection |
| `:s/pat/rep/` | substitute on current line; add `g` for all matches, `%` before `s` for whole file |

## Editing — Insert mode

| Key | Does |
| --- | ---- |
| `Esc` | back to Normal mode |
| arrow keys | move cursor (breaks the insert "undo chunk") |
| `Ctrl-Up` / `Ctrl-Down` **(this config)** | half-page scroll, same as Normal mode |
| `Ctrl-a` / `Ctrl-e` **(this config)** | jump to start / end of line, same as `Home`/`End` |
| `Ctrl-w` | delete word before cursor |
| `Ctrl-u` | delete to start of line |
| `Ctrl-t` / `Ctrl-d` | indent / outdent current line |
| `Ctrl-o` | run one Normal-mode command, then return to Insert |
| `Ctrl-r {reg}` | insert contents of register `reg` (e.g. `Ctrl-r "` for last yank/delete) |
| `Ctrl-n` / `Ctrl-p` | next / previous keyword completion match |
| `Ctrl-v {code}` | insert a literal character by code |
| paste (`Cmd-V`/`Super-V`) | bracketed paste — no auto-indent staircase, no mapping needed |

## Command-line mode (`:`, `/`, `?`)

| Key | Does |
| --- | ---- |
| `:` | enter command-line mode |
| `/pattern`, `?pattern` | search forward / backward |
| `n` / `N` | repeat last search, same / opposite direction |
| `Ctrl-a` / `Ctrl-e` | start / end of the command line (vim default here, unaffected by the Normal/Insert remap above) |
| `Tab` | complete command/filename |
| Up / Down or `Ctrl-p` / `Ctrl-n` | previous / next command-line history entry |
